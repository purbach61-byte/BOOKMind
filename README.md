# 📚 BookMind — Book Recommendation System

BookMind is a web-based book recommendation application built with Python and Flask. It allows users to explore books and get recommendations through a simple and responsive interface.

## 🚀 Live Demo

https://bookmind-1-o1tw.onrender.com

## ✨ Features

- 📚 Browse available books
- 🔍 Get book recommendations
- 🎨 Responsive web interface
- 🗄️ MongoDB Atlas database
- ⚡ Flask backend
- 🌐 Deployed on Render

## 🛠️ Tech Stack

- Python
- Flask
- MongoDB Atlas
- HTML
- CSS
- JavaScript
- Git & GitHub
- Render
